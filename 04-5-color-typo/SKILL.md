# 컬러 팔레트 및 타이포그래피 제안

주어진 컨셉을 바탕으로 실무에서 바로 사용할 수 있는 컬러와 타이포그래피 시스템을 제안합니다.

## 작업 순서

1. 사용자의 요청에서 브랜드 키워드(예: 신뢰감, 경쾌함, 전문성)와 목적(예: B2B 어드민, 쇼핑몰)을 파악합니다.
2. `references/design-tokens.md`에 정의된 허용 색상(Tailwind 기반)과 폰트 스케일 내에서만 제안을 구성합니다.
3. 임의의 HEX 값이나 폰트 크기를 새로 만들지 않으며, 반드시 시스템 내의 토큰(예: `blue-600`, `text-lg`)을 매핑합니다.
4. 아래 체크리스트로 자가 점검한 뒤 결과를 코드 블록(CSS 변수 또는 Tailwind config) 형태로 보고합니다.

## 핵심 규약

- **색상 수 제한:** Primary, Secondary, Error, Warning, Success의 5가지 시맨틱 컬러만 지정합니다. 명도 단계(50~900)는 필요 시에만 추가합니다.
- **타이포그래피 계층:** Heading(1~4), Body, Caption의 6단계만 허용합니다.
- **접근성:** 텍스트와 배경 색상 조합은 반드시 WCAG 2.1 AA 등급(명도비 4.5:1 이상)을 만족해야 합니다.
- **포맷팅:** 산출물은 설명 텍스트를 최소화하고, 개발자가 즉시 복사할 수 있는 설정 파일 조각으로 출력합니다.

## 체크리스트

작성 후 다음을 확인하고, 하나라도 어긋나면 고친 뒤 보고합니다.

- [ ] 시스템에 없는 임의의 HEX 값이나 px 값을 사용하지 않았다
- [ ] 텍스트와 배경의 명도비가 4.5:1 이상이다
- [ ] Primary, Secondary 등 5가지 핵심 색상이 포함되었다
- [ ] 개발자가 바로 쓸 수 있는 코드 블록이 있다
