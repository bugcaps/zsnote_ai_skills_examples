# 이메일 뉴스레터 작성

전달받은 링크와 기사를 바탕으로 지정된 템플릿에 맞춰 뉴스레터를 작성합니다.

## 작업 순서

1. 사용자가 제공한 기사나 링크의 핵심 내용을 파악하고, 각 기사당 3줄 이내로 요약합니다.
2. `assets/template.md` 파일을 읽어 뉴스레터의 시각적 구조와 플레이스홀더(`{{}}`)를 파악합니다.
3. 템플릿의 구조를 절대 임의로 변경하지 말고, 플레이스홀더만 요약한 내용으로 치환합니다.
4. 완성된 뉴스레터 초안을 사용자에게 제공하고, 아래 체크리스트로 자가 점검합니다.

## 핵심 규약

- **디자인과 내용의 분리:** 에이전트는 레이아웃을 생성하지 않습니다. 양식은 템플릿에 완전히 위임합니다.
- **길이 제한:** 각 기사의 요약은 독자가 빠르게 읽을 수 있도록 3줄을 넘지 않습니다.
- **출처 명시:** 요약 내용 하단에는 반드시 원본 기사로 이동할 수 있는 링크를 포함합니다.
- **어조 유지:** 뉴스레터는 친근하되 전문성을 잃지 않는 경어체(~합니다, ~습니다)를 사용합니다.

## 체크리스트

작성 후 다음을 확인하고, 하나라도 어긋나면 고친 뒤 보고합니다.

- [ ] `assets/template.md` 템플릿 파일을 실제로 읽었다
- [ ] 템플릿의 마크업 구조를 임의로 수정하거나 삭제하지 않았다
- [ ] 모든 플레이스홀더가 내용으로 치환되었다
- [ ] 각 요약은 3줄 이내이며 원본 링크가 포함되었다
