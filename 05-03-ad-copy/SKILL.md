# 광고 카피 및 A/B 테스트 문안 작성

사용자가 광고 카피나 A/B 테스트 문안을 요청하면 다음 지침을 따릅니다.

## 작업 지침

1. **테스트 변수 설정**: A/B 테스트의 목적(예: 혜택 강조 vs 위협/결핍 소구, 캐주얼 톤 vs 전문가 톤)을 명확히 설정합니다.
2. **단일 변수 통제**: 두 시안(A와 B)은 철저히 '하나의 변수'만 달라야 합니다. (예: 이미지가 동일하다면 카피의 톤앤매너만 다르게)
3. **가이드라인 참조**: `assets/brand_voice.md`를 읽고 브랜드 톤앤매너와 금지어 규정을 숙지합니다.
4. **결과물 출력**: A/B 테스트 카피 결과를 `assets/ad_template.md`의 양식에 맞춰 작성하여 아티팩트로 제공합니다.

## 제약 사항

- 모호한 형용사(최고의, 완벽한 등)는 배제하고 구체적인 숫자나 혜택을 명시합니다.
- 반드시 시안 간의 '기대 효과'와 '테스트 목적'을 설명해야 합니다.
- A안은 대조군(기존/안전한 방식), B안은 실험군(새로운 소구점)으로 구성합니다.

## 자가 점검 체크리스트

- [ ] 브랜드 톤앤매너(금지어 포함)를 준수했는가?
- [ ] A안과 B안의 차이점(단일 변수)이 명확한가?
- [ ] 모호한 형용사를 배제하고 구체적으로 작성했는가?
- [ ] 지정된 템플릿 양식대로 출력했는가?
