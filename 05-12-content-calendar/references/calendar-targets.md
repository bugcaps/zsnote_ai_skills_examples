# 기록처 판정과 필드 매핑

SKILL.md 3단계에서 읽습니다. 캘린더 표를 **어디에** 쓸지 정하고, 표의 열을 그 도구의 속성에 맞춥니다.

## 1. 판정 순서

위에서부터 확인하고, 먼저 해당하는 경로로 갑니다. 도구 이름이 아니라 **할 수 있는 일**로 판정합니다.

| 순서 | 확인할 것 | 해당하면 |
| :--- | :--- | :--- |
| 1 | 노션 계열: 데이터베이스를 검색하고 **페이지를 새로 만들 수 있는** 도구가 있는가 | 주 경로 A |
| 2 | 캘린더 계열: 캘린더 목록과 **기간 내 일정을 읽고**, **일정을 새로 만들 수 있는** 도구가 있는가 | 주 경로 B |
| 3 | 읽기만 가능하거나 아무것도 없는가 | 대체 경로 C |

읽기 도구만 있으면 쓰기가 가능한 것으로 취급하지 않습니다. 경로 C입니다.
**커넥터 안내 문구만 있고 실제로 호출할 수 있는 생성 도구가 없으면 경로 C입니다.** 지침이나 설명이 보이는 것과 도구를 부를 수 있는 것은 다릅니다.
쓰기는 되지만 **기간 내 기존 항목을 조회할 수 없으면 중복 판정 수단이 없으므로 경로 C로 내립니다.** 조회가 안 된다는 사실을 사용자에게 알립니다.
경로 A·B에서는 대상 데이터베이스·캘린더를 **검색해서 사용자에게 이름을 보여주고 고르게 합니다.** 이름을 추측해 쓰지 않습니다.

## 2. 필드 매핑

캘린더 표의 열 → 기록처 속성입니다. 대상에 없는 속성은 만들지 않고 건너뛰되, 무엇을 버렸는지 보고합니다.

| 표의 열 | 경로 A(노션 계열) | 경로 B(캘린더 계열) | 경로 C(CSV) |
| :--- | :--- | :--- | :--- |
| 발행일 | 날짜 속성 | 시작일(종일 일정) | `발행일` |
| 요일 | 쓰지 않음(날짜에서 계산됨) | 쓰지 않음 | `요일` |
| 채널 | 선택(Select) 속성 | 제목 앞에 `[채널]` | `채널` |
| 주제 | 제목 속성 | 제목 | `주제` |
| 형식 | 선택 속성 | 설명 첫 줄 | `형식` |
| 담당 | 텍스트 속성(사람 멘션 대신 이름 문자열) | 설명 둘째 줄 | `담당` |
| 상태 | 상태/선택 속성, 값은 `예정` | 설명 셋째 줄 | `상태` |

- 경로 B의 일정은 **종일 일정**으로 만듭니다. 발행 시각까지 정해 달라는 요청이 없으면 시간을 임의로 넣지 않습니다.
- 대상에 없는 선택지 값(예: `인스타그램`)을 새로 추가해야 하면, 추가한다는 사실을 4단계 확인에 포함합니다.
- 중복 판정: 쓰기 전에 대상에서 같은 기간을 조회해 **같은 발행일 + 같은 채널**이 있으면 그 항목만 건너뜁니다.

## 3. CSV 스펙 (경로 C)

- 열 이름과 순서: `발행일,요일,채널,주제,형식,담당,상태`
- 날짜 형식: `YYYY-MM-DD` (예: `2026-10-06`)
- 인코딩: `utf-8-sig`, 줄바꿈 `\n`. 노션 임포트와 엑셀에서 한글이 깨지지 않는 조합입니다.
- `상태`의 기본값은 `예정`. `주제`·`형식`·`담당`은 비어 있어도 됩니다.

## 4. 스크립트 사용법

요일 → 실제 날짜 환산과 CSV 저장을 스크립트에 맡깁니다. 아래 명령을 그대로 실행합니다(추가 설치 없음).

```
python scripts/make_calendar_csv.py --start 2026-10-01 --weeks 4 \
  --slot "블로그:화" --slot "인스타그램:금" \
  --topics "가을 신제품 티저,사용법 3단계,고객 후기 모음,자주 묻는 질문" \
  --output content-calendar-2026-10.csv
```

- `--slot "채널:요일"`은 발행 슬롯 하나입니다. 채널이 여러 개면 여러 번 씁니다.
- **저장 경로는 사용자에게 확인하거나 작업 폴더 안으로 지정합니다.** 기존 파일은 덮어쓰지 않으므로 `content-calendar-2026-10.csv`처럼 날짜를 붙인 이름을 권합니다.
- `--topics`는 쉼표로 구분하고 **채널 구분 없이 날짜 순서대로** 채워집니다. 위 예시에서 첫 주제는 블로그가 아니라 가장 이른 날짜인 인스타그램 항목에 들어갑니다. 채널별로 주제를 나눠 주는 옵션은 없으니, 채널별 배정이 중요하면 슬롯을 한 개만 두고 채널마다 따로 실행하거나 표에서 직접 배정합니다. 주제가 모자라면 뒤쪽 항목의 주제가 빕니다.
- 스크립트는 `형식`·`담당` 열을 **항상 비워 둡니다.** 값이 필요하면 CSV를 만든 뒤 사람이 채우거나 캘린더 표에만 적습니다.
- 채널별로 **첫 발행일이 달라 구간이 어긋납니다.** 위 예시는 인스타그램 10-02~10-23, 블로그 10-06~10-27이 되고 10-30(금)은 4주 범위를 넘어 빠집니다. 월말까지 채워야 하면 `--start`를 조정해 다시 확인합니다.
- `--dry-run`을 붙이면 파일을 만들지 않고 생성될 행만 출력합니다. 날짜가 맞는지 먼저 볼 때 씁니다.
- 종료 코드: `0` 성공 / `1` 같은 이름의 파일이 이미 있어 쓰지 않음(다른 이름으로 다시 실행) / `2` 입력 오류.
- `--weeks`는 최대 4입니다. 5 이상을 넣으면 종료 코드 2로 거부합니다.
