# SVG 아이콘 및 로고 시안 생성

요청받은 아이콘이나 로고를 디자인 도구 없이 SVG 코드로 즉시 생성하여 시각적 시안을 제공합니다.

## 작업 지침

1. **가이드라인 숙지**: `references/svg-style-guide.md` 파일에 정의된 브랜드 색상, 선 두께(stroke-width), 기본 크기(viewBox) 등의 규칙을 먼저 읽고 정확히 준수합니다.
2. **코드만 출력**: 불필요한 설명 없이 즉시 브라우저나 마크다운 뷰어에서 렌더링될 수 있도록 완전한 `<svg>` 태그 형태의 코드를 작성합니다.
3. **단순함 유지**: 복잡한 패스(path) 연산보다는 기본 도형(rect, circle, line 등)과 명확한 패스를 조합하여 간결하고 유지보수하기 쉬운 SVG를 생성합니다.
4. **접근성 속성 추가**: 아이콘의 의미를 스크린 리더가 읽을 수 있도록 `role="img"`와 `<title>` 태그를 반드시 포함합니다.
5. **렌더링 확인**: 생성한 SVG를 브라우저나 마크다운 뷰어에서 실제로 열어 의도한 모양인지 확인합니다. 문법이 맞아도 패스 좌표가 어긋나면 알아볼 수 없는 도형이 나옵니다.

## 자가 검토 체크리스트

코드를 반환하기 전 다음 사항을 확인합니다.

- [ ] `references/svg-style-guide.md`의 브랜드 색상(Primary/Secondary)을 사용했는가?
- [ ] 가이드에 적힌 명암비가 3:1 이상인 색을 골랐는가? (아이콘은 그래픽 요소 기준)
- [ ] `viewBox` 속성이 가이드라인(예: 0 0 24 24)에 맞게 설정되었는가?
- [ ] `stroke-width`와 `stroke-linecap` 등 선 스타일이 일관된가?
- [ ] 의미를 설명하는 `<title>` 태그가 포함되었는가?
- [ ] 렌더링해서 의도한 모양인지 눈으로 확인했는가?
