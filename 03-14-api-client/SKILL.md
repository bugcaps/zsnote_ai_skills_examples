# 외부 API 연동 클라이언트 생성

제공된 OpenAPI 명세 등 외부 명세서를 바탕으로, 타입 안전(Type-safe)하고 프로젝트 표준 에러 처리가 적용된 API 클라이언트를 생성합니다.

## 작업 순서

1. `references/api-specs/` 폴더에서 대상 API 명세서(JSON 또는 YAML)를 읽습니다.
2. 명세서에 정의된 Request/Response 스키마를 바탕으로 TypeScript 인터페이스를 도출합니다.
3. 명세서에 정의된 각 엔드포인트에 대응하는 API 호출 함수를 작성합니다.
4. 명세의 `required` 배열에 없는 속성은 선택적(`?`)으로, `enum`은 문자열 유니온으로 옮깁니다.
5. 아래 체크리스트로 자가 점검 후 최종 코드를 보고합니다.

## 핵심 규약

- **`any` 타입은 절대 사용하지 않습니다.** 응답 타입을 반드시 명세에서 추출하여 적용합니다.
- **명세에 없는 엔드포인트·필드·상태 코드를 추측해서 만들지 않습니다.** 요청받은 API가 명세에 없으면 작성하지 않고 그 사실을 알립니다.
- Fetch API를 직접 쓰지 않고 프로젝트 내부 HTTP 클라이언트 래퍼(예: `src/lib/apiClient.ts`)를 사용합니다. 래퍼의 실제 경로와 사용법은 기존 API 클라이언트 파일 1개를 읽어 확인합니다.
- 함수명은 `[동사][리소스명]`(예: `getUserProfile`) 형태로 명명합니다.
- 예외 발생 시 원본 에러를 던지지 않고, 프로젝트 공통 에러 객체(`AppError`)로 래핑해야 합니다.

## 체크리스트

작성 후 다음을 확인하고, 하나라도 어긋나면 고친 뒤 보고합니다.

- [ ] 요청 및 응답에 대한 TypeScript 인터페이스가 모두 정의되었다
- [ ] `any` 타입이 코드 내에 단 한 번도 사용되지 않았다
- [ ] 에러 처리가 누락되지 않고 프로젝트 공통 규약을 따른다
- [ ] 명세서의 엔드포인트 URL과 파라미터가 정확히 매핑되었다
