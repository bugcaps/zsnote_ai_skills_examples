# 노트 양식과 인용 규약

## 노트 양식

```
# {{ 원문 제목 그대로 · 없으면 제목미상 }}

- 태그: {{ #주제태그 #용도태그 — 태그목록.md에서만 고른 3~5개 }}
- 한 줄 요지: {{ 이 글이 주장하는 바 한 문장, 60자 이내 }}
- 원제: {{ 번역서·번역 기사라 원제가 따로 있을 때만. 없으면 이 줄을 지웁니다 }}
- 출처: {{ 지은이 또는 매체 }} · 발행 {{ YYYY-MM-DD 또는 날짜미상 }} · {{ 원문을 다시 찾을 경로 }}
- 읽은 범위: {{ 전체 | 부분(어디까지 읽었는지) }}
- 찾을 말: {{ 6개월 뒤에 떠올릴 말 3개 }}

## 노트

> {{ 원문 문장 그대로 }} (위치: {{ 3장 | 12쪽 | 소제목명 | 4번째 문단 | 중반부 | 위치 미상 }})
- {{ 원문에 있는 내용을 내 문장으로 줄인 것 }}
- (생각) {{ 원문에 없는 내 해석·반론·연결 }}
```

제목 줄과 그 아래 여섯 줄을 본문보다 먼저 채웁니다. 이 순서를 바꾸지 않습니다. 맨 앞의 **제목·태그·한 줄 요지가 검색 키**이고, 원제·출처·읽은 범위는 노트를 열었을 때 원문으로 돌아가기 위한 줄입니다.

`찾을 말` 세 개는 모두 제목·태그·한 줄 요지 안에서 **글자 그대로** 찾을 수 있어야 합니다. 하나라도 없으면 찾을 말을 고치는 것이 아니라 제목·태그·요지를 고칩니다. 이 줄은 검색 키를 검산하는 자리이지 네 번째 검색 키가 아닙니다.

## 세 가지 표기

| 표기 | 무엇 | 지켜야 할 것 |
| :--- | :--- | :--- |
| `> ` | 인용. 원문에 있는 문장 그대로 | 한 글자도 고치지 않습니다. 중간을 줄임표로 생략하지 않습니다. 끝에 위치를 붙입니다 |
| `- ` | 요약. 원문에 있는 내용을 내 문장으로 줄인 것 | 원문에 없는 주장을 넣지 않습니다 |
| `- (생각) ` | 내 해석·반론·연결. 원문에 없는 것 | 원문의 주장인 것처럼 적지 않습니다 |

- **표기 없는 줄을 노트에 남기지 않습니다.** 본문의 모든 줄은 셋 중 하나입니다.
- **한 줄에 두 표기를 섞지 않습니다.** 인용 뒤에 바로 감상을 붙이지 말고 줄을 나눕니다.
- 인용문을 다듬거나 줄였다면 그것은 인용이 아니라 요약입니다. `> `를 `- `로 바꿉니다.
- 위치는 **원문에 실제로 있는 단위**로 적습니다. 양식에 적힌 표기는 예시이며 닫힌 목록이 아닙니다. 장·쪽·소제목이 없는 글이라면 `4번째 문단`, `2절`, `중반부`처럼 **다시 짚어 갈 수 있는 말**로 적고, 한 노트 안에서는 같은 방식으로 통일합니다.
- 그래도 위치를 짚을 수 없으면 지어내지 말고 `(위치: 위치 미상)`으로 둡니다.

6개월 뒤에 노트를 다시 열었을 때 **어느 문장이 지은이의 말이고 어느 문장이 내 말인지**를 이 표기 하나로 가릅니다. 섞인 줄은 나중에 갈라낼 방법이 없고, 남에게 옮길 때 지은이가 하지 않은 말을 지은이의 주장으로 전하게 됩니다.

## 인용 분량 상한

원문은 남의 저작물입니다. 노트는 요약본이지 사본이 아닙니다.

| 항목 | 상한 |
| :--- | :--- |
| 노트 하나의 인용 개수 | 5개 |
| 인용 하나의 길이 | 3문장 |
| 노트 하나의 인용 글자 수 합계 | 500자 |

- 상한을 넘으면 인용을 요약(`- `)으로 바꿉니다. 어느 것을 남길지는 **한 줄 요지를 뒷받침하는 문장** 순으로 고릅니다.
- 사용자가 원문 전문을 노트에 넣어 달라고 해도 넣지 않고, 대신 `출처` 줄로 원문을 찾아가게 합니다.
- 표·그림·가사·시처럼 짧은 저작물은 통째로 옮기기 쉬우므로 인용하지 말고 무엇이 있었는지만 요약으로 적습니다.

## 한 줄 요지를 쓰는 법

| 이렇게 쓰면 다시 찾지 못합니다 | 이렇게 씁니다 |
| :--- | :--- |
| 잠에 대한 글 | 모자란 잠은 주말에 되갚아지지 않고 쌓여서 판단력부터 갉아먹는다 |
| 회의 문화를 다룬다 | 회의를 줄이는 것보다 참석자를 줄이는 쪽이 효과가 크다 |
| 저자의 경험담을 소개한다 | 혼자 일하는 시간을 확보하려면 일정을 비우는 것이 아니라 먼저 채워야 한다 |

왼쪽은 어느 노트에나 붙는 말이라 검색 결과를 좁혀 주지 못합니다. 오른쪽은 그 노트에만 붙습니다.

주장이 없는 자료성 문서(설명서·통계표·용어집)라면 억지로 주장을 만들지 말고 `주장 없음 — {{ 무엇을 찾을 때 쓰는 자료인지 }}`라고 적습니다.

## 연습용 샘플

`data/sample-article.md`는 지어낸 칼럼 한 편이고, `data/notes/`는 이미 쌓여 있다고 가정한 노트 3편과 `태그목록.md`입니다. 실존 도서·저자·매체와 무관합니다.
연습할 때는 `data/notes/`가 노트 폴더입니다. `태그목록.md`와 기존 노트를 거기서 읽되 `data/` 안의 파일은 **읽기만** 하고, 새로 만든 노트는 사용자가 지정한 다른 폴더에 저장합니다.
