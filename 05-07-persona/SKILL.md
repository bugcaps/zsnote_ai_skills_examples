# 고객 페르소나 및 여정 지도 생성기

## 1. 작업 순서
1. 입력된 ProductInfo를 분석하여 핵심 타겟 고객 1인을 선정합니다.
2. 선정된 고객의 '페르소나'를 상세히 작성합니다. (이름, 나이, 직업, 목표, 통점)
3. 해당 고객의 5단계(인지, 탐색, 구매, 사용, 추천) '고객 여정 지도'를 작성합니다.

## 2. 핵심 규약
- 여정 지도는 반드시 Markdown 표 형식으로 작성합니다.
- 각 단계별로 행동, 생각, 감정, 터치포인트, 통점(Pain Points)을 구체적으로 도출합니다.

## 3. 체크리스트
- [ ] 페르소나에 목표와 통점이 명확히 드러났는가?
- [ ] 여정 지도가 5단계로 빠짐없이 작성되었는가?
- [ ] 결과물이 Markdown 표 형식인가?
