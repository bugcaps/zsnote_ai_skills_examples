# 동적 웹 페이지 데이터 수집

수집해도 되는지는 스크립트가 먼저 판정합니다. 에이전트는 판정이 끝난 뒤에야 페이지를 엽니다.

## 작업 순서

1. **허용 확인**: `python scripts/scrape.py <URL> --check-only`를 실행합니다. exit 1이면 `[중단]` 메시지를 그대로 보고하고 멈춥니다. 이 단계 전에는 대상 페이지를 열지 않습니다.
2. **API 먼저**: 대상 서비스에 **문서로 공개된** API나 데이터 내려받기가 있는지 사용자에게 묻습니다. 있으면 그쪽을 권합니다. 네트워크 탭에서 찾은 비공식 엔드포인트는 예고 없이 바뀌므로 쓰지 않습니다.
3. **셀렉터 찾기**: `references/playwright-setup.md`의 "셀렉터 찾기" 순서대로 **렌더링된 DOM**에서 항목·필드 셀렉터를 정합니다. 값이 여러 개인 필드는 `이름[]=셀렉터`로 씁니다.
4. **쪽 수 확인**: 사용자가 "전부"를 원하고 다음 쪽 링크가 있으면, 쪽 수와 간격(`--delay`, 기본 2초)을 사용자에게 확인받습니다.
5. **실행**: `python scripts/scrape.py <URL> --item "<항목>" --field "이름=<셀렉터>" ... [--pages N --next "<링크>"] --output <사용자 작업 폴더>/result.json`. 결과는 스킬 폴더 밖, 사용자가 명령을 실행한 폴더에 저장합니다.
6. **판정**:
   - exit 1이면 `[중단]` 메시지를 그대로 보고하고 멈춥니다. 원인을 우회하지 않습니다. 도구가 없다는 메시지면 설치 명령을 안내합니다.
   - exit 0이어도 `빈 필드`가 1개 이상이면 빈 항목의 DOM을 확인합니다. 셀렉터 문제면 고치고 5로 돌아가고, 원본에 값이 없으면 그 사실을 보고에 적습니다.
7. **보고**: 쪽 수, 건수, 빈 필드 수, 첫 3건 미리보기를 보여 줍니다. 수치는 `result.json`에 있는 값만 씁니다.

## 핵심 규약

- robots.txt가 금지하거나 확인되지 않으면 수집하지 않습니다. User-Agent 위장, 로그인 우회, 캡차 우회를 하지 않습니다.
- 쪽 수를 사용자가 정하지 않았으면 1쪽만 수집합니다. 쪽 사이 간격은 1초 이상입니다(스크립트가 막습니다).
- 항목이 0건이면 "데이터 없음"이 아니라 수집 실패입니다. 셀렉터가 틀렸을 가능성을 먼저 봅니다.
- 원본 HTML을 저장하지 않습니다. 추출한 필드만 남깁니다.
- 실행하지 않은 결과 예시나 수치를 지어내지 않습니다.

## 체크리스트

- [ ] 페이지를 열기 전에 `--check-only`로 robots.txt를 확인했다
- [ ] 셀렉터를 렌더링된 DOM에서 찾았고, 여러 값 필드는 `[]`로 받았다
- [ ] 2쪽 이상은 사용자 확인을 받았다
- [ ] exit 1이면 우회하지 않고 멈췄다
- [ ] 빈 필드가 0개이거나, 빈 이유를 보고했다
- [ ] 보고한 건수·값이 `result.json`과 같다
