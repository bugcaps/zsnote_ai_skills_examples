# 프론트엔드 UI 컴포넌트 생성

이 프로젝트의 컴포넌트 규약을 따르는 React 컴포넌트를 만듭니다.

## 작업 순서

1. **기존 컴포넌트를 먼저 읽습니다.** `src/components/` 에서 가장 유사한 컴포넌트 1개를 읽고, 그 파일의 import 순서·props 정의 방식·스타일 기법을 그대로 따릅니다. 규약과 실제 코드가 다르면 **실제 코드가 우선**입니다.
2. 컴포넌트가 상태를 갖는지 판단합니다. 상태가 없으면 순수 표현 컴포넌트로 만들고, `useState`를 넣지 않습니다.
3. [references/component-conventions.md](references/component-conventions.md) 의 규약을 적용해 작성합니다.
4. 아래 체크리스트로 자가 점검한 뒤 결과를 보고합니다.

## 핵심 규약

- **props 인터페이스는 컴포넌트 바로 위에** `ComponentNameProps` 이름으로 선언합니다.
- **boolean props를 3개 이상 만들지 않습니다.** 3개가 넘으면 variant 문자열 유니온으로 합칩니다.
- **접근성 속성은 선택이 아닙니다.** 상호작용 요소에는 이름(`aria-label` 또는 보이는 텍스트)과 키보드 포커스가 반드시 있어야 합니다.
- **default export를 쓰지 않습니다.** named export만 사용합니다.
- 스타일 값은 하드코딩하지 않고 디자인 토큰을 참조합니다.

## 체크리스트

작성 후 다음을 확인하고, 하나라도 어긋나면 고친 뒤 보고합니다.

- [ ] 유사 기존 컴포넌트 1개 이상을 실제로 읽었다
- [ ] boolean props 3개 미만
- [ ] 상호작용 요소에 접근 가능한 이름이 있다
- [ ] named export만 존재한다
- [ ] 하드코딩된 색상·간격 값이 없다
