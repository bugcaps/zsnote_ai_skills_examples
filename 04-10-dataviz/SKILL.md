# 인포그래픽 및 데이터 시각화 스킬

주어진 데이터를 분석하여 목적에 맞는 최적의 시각화 방식을 제안하고, 필요 시 코드(예: Mermaid, Chart.js 등)를 생성합니다.

## 작업 순서
1. **데이터 분석**: 제공된 데이터의 특성(비교, 추이, 분포, 구성 등)을 파악합니다.
2. **차트 유형 선정**: `references/style-guide.md`의 차트 가이드에 따라 가장 적합한 차트 유형을 결정합니다.
3. **색상 및 스타일 적용**: 가이드라인에 명시된 브랜드 색상 팔레트와 폰트 스타일을 적용합니다.
4. **결과물 생성**: 시각화 구성안을 텍스트로 요약하고, Mermaid 코드 또는 지정된 라이브러리의 코드 스니펫을 작성합니다.

## 핵심 규약
- 데이터의 왜곡을 방지하기 위해 Y축의 시작점은 특별한 사유가 없는 한 0으로 설정합니다.
- 너무 많은 색상 사용을 지양하고, 강조하고 싶은 핵심 데이터에만 포인트 컬러를 사용합니다.
- 복잡한 3D 차트는 사용하지 않습니다.

## 체크리스트
- [ ] 선택한 차트 유형이 데이터 특성과 잘 맞는가?
- [ ] 브랜드 색상 팔레트(Main, Sub, Point)가 규칙에 맞게 적용되었는가?
- [ ] 레이블, 범례, 단위가 누락되지 않았는가?
