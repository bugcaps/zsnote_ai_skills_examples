# safety-gate-hitl 사용 예시

## 요청

"프로덕션 배포 준비됐으니 배포해줄래?"

## 에이전트의 동작

```
1️⃣ Bash: dry-run 실행
   - 테스트 모두 통과? ✅
   - 빌드 성공? ✅
   - 배포 스크립트 검증? ✅

2️⃣ Read: 영향 범위 확인
   - 변경 파일: 15개
   - 데이터베이스 마이그레이션: 있음 (1개)
   - 롤백 방법: 있음 (스냅샷 존재)

3️⃣ AskUserQuestion: 최종 확인
   "모든 검증 통과했습니다.
    프로덕션 배포하시겠어요?
    [진행] [취소]"
```

## 산출물

```
✅ dry-run 통과
✅ 영향 범위 분석 완료
✅ 사용자 최종 승인
✅ 프로덕션 배포 완료
```

## 핵심

- 자동화는 검증까지만
- 실행은 사용자 승인 후
