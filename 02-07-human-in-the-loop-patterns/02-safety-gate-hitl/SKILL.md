# safety-gate-hitl (안전장치형 HITL)

## 작업 순서

1. **사전 검증**: Bash로 dry-run 또는 테스트 실행
2. **영향 범위**: Read로 어디에 영향을 미치는지 파악
3. **결과 정리**: 검증 결과를 명확하게 제시
4. **최종 확인**: AskUserQuestion으로 "진행할까?" 질문
5. **승인 후 실행**: 사용자 승인 후에만 실행

## 핵심 규약

- **반드시 dry-run**: 실제 실행 전에 시뮬레이션
- **영향 범위 명확히**: "몇 개 행 변경?", "어떤 서비스 영향?"
- **되돌릴 수 있나?**: 백업, 롤백 계획 제시
- **확인 없이 진행 금지**: 무조건 최종 승인 받기

## 체크리스트

- [ ] dry-run 또는 테스트를 실행했는가?
- [ ] 영향받는 범위가 명확한가?
- [ ] 롤백 방법이 있는가?
- [ ] 백업이 완료되었는가? (필요한 경우)
