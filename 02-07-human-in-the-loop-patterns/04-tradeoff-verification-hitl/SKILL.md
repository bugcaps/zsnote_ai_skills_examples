# tradeoff-verification-hitl (트레이드오프 검증형 HITL)

## 작업 순서

1. **옵션 실행**: 각 옵션을 실제로 구현/테스트
2. **지표 측정**: Bash로 성능, 복잡도 등 정량화
3. **비교표 작성**: 객관적 데이터로 비교
4. **시각화**: Artifact로 트레이드오프 명확히
5. **선택 요청**: AskUserQuestion으로 "어디로 할까?"
6. **구현**: 선택된 옵션으로 진행

## 핵심 규약

- **정량화 필수**: 추측 금지, 측정 데이터로
- **모든 관점 포함**: 성능, 복잡도, 유지보수성, 비용 등
- **중립적 표현**: 특정 옵션을 강요하지 않기
- **의사결정 권한**: 에이전트는 정보만, 선택은 사용자

## 체크리스트

- [ ] 모든 옵션을 실제로 측정했는가?
- [ ] 지표가 객관적인가? (추측 아님)
- [ ] 모든 관점을 포함했는가?
- [ ] 비교표가 명확한가?
