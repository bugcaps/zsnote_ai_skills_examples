# error-analysis-hitl (오류 분석형 HITL)

## 작업 순서

1. **오류 재현**: Bash로 문제 재현
2. **원인 분석**: Grep/Read로 오류의 원인 파악
3. **가능한 원인**: 여러 가능성 제시
4. **각 원인별 해결법**: 원인별로 해결 경로 제시
5. **선택 요청**: AskUserQuestion으로 "어느 방법으로?"
6. **수정**: 선택된 방법으로 진행

## 핵심 규약

- **자동 수정 금지**: 원인이 명확할 때만 수정
- **여러 가능성**: 한 가지가 아닌 복수 원인 제시
- **각 경로 명확히**: 각 선택의 결과 설명
- **데이터 제시**: 추측 아닌 로그/오류 메시지로

## 체크리스트

- [ ] 오류를 재현했는가?
- [ ] 가능한 모든 원인을 찾았는가?
- [ ] 각 원인별 로그/증거가 있는가?
- [ ] 각 해결법의 영향 범위가 명확한가?
