# error-analysis-hitl 사용 예시

## 요청

"테스트 3개 실패했는데 뭐가 문제야?"

## 에이전트의 동작

```
1️⃣ Bash: 테스트 재실행 & 오류 로그 분석
   → 3개 테스트 실패 원인 찾기

2️⃣ 오류 분석 결과:
   원인 1: 데이터베이스 연결 타임아웃
   원인 2: Mock 데이터 구조 변경
   원인 3: 비동기 함수 대기 시간 부족

3️⃣ AskUserQuestion: 해결 경로 선택
   "3가지 원인을 찾았습니다:
   
   1) DB 타임아웃
      → 해결: DB 연결 대기시간 증가
      → 시간: 5분
   
   2) Mock 데이터 변경됨
      → 해결: Mock 데이터 업데이트
      → 시간: 10분
   
   3) 비동기 대기 부족
      → 해결: setTimeout(5000) 추가
      → 시간: 2분
   
   어디부터 고칠까요?
   [1번부터] [2번부터] [3번부터] [모두]"
```

## 산출물

```
✅ 3가지 오류 원인 분석 완료
✅ 각 원인별 해결 방법 제시
✅ 각 해결법의 시간 추정
✅ 사용자 선택: 모두 고치기
✅ 테스트 재실행: ✅ 모두 통과
```

## 핵심

- 원인 분석은 철저히
- 자동 수정은 확신할 때만
