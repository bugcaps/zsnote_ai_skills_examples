# clarification-hitl (불확실성 해소형 HITL)

## 작업 순서

1. **상황 분석**: Read로 기존 코드/요구사항 파악
2. **의혹 지점 파악**: "어디가 불명확한가?"
3. **가능한 해석**: 여러 해석을 제시
4. **질문 제시**: AskUserQuestion으로 "이중 어느 것?"
5. **명확화 후 진행**: 사용자의 선택에 따라 진행

## 핵심 규약

- **가정하지 말기**: 불명확하면 무조건 물어보기
- **여러 해석 제시**: 가능한 모든 해석을 제시
- **구체적 예제**: 각 해석의 결과를 구체적으로
- **복잡하면 나누기**: 너무 많은 질문은 분할

## 체크리스트

- [ ] 정말 불명확한가? (확실한 부분은 진행)
- [ ] 가능한 모든 해석을 제시했는가?
- [ ] 각 해석의 코드 예제가 있는가?
- [ ] 사용자가 쉽게 선택할 수 있는가?
