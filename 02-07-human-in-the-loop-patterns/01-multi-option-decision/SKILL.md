# multi-option-decision (의사결정형 HITL)

## 작업 순서

1. **현황 분석**: Read로 기존 상황 파악
2. **선택지 도출**: 가능한 옵션 3~4개 정의
3. **비교 자료**: 각 옵션의 장단점 정리
4. **시각화**: Artifact로 선택지 명확히
5. **선택 요청**: AskUserQuestion으로 사용자 선택
6. **선택 결과**: 선택된 옵션 기반 진행

## 핵심 규약

- **선택지는 3~4개**: 너무 많으면 선택 마비
- **각 옵션의 결과 명시**: 선택 후 어떻게 되는지
- **근거 제시**: 왜 이 옵션들을 제시했는지
- **중립적 설명**: 특정 옵션을 강요하지 않기

## 체크리스트

- [ ] 선택지가 3~4개인가? (너무 많지 않나?)
- [ ] 각 선택지의 장단점이 명확한가?
- [ ] 시각화가 의사결정을 도와주는가?
- [ ] 사용자가 정보 부족으로 선택 불가능하지는 않은가?
