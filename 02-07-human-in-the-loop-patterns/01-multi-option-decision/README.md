# multi-option-decision 사용 예시

## 요청

"아키텍처를 monolith로 할까, microservices로 할까?"

## 에이전트의 동작

```
1️⃣ Read: 현재 프로젝트 규모, 팀 규모, 성능 요구사항 분석

2️⃣ Artifact: 3가지 설계안 비교
   - 옵션 A: Monolith (간단, 배포 빠름, 확장 어려움)
   - 옵션 B: Microservices (복잡, 배포 느림, 확장 쉬움)
   - 옵션 C: Hybrid (중간 수준)

3️⃣ AskUserQuestion: "어느 옵션으로 할까요?"
   [옵션 A] [옵션 B] [옵션 C]
```

## 산출물

```
✅ 3가지 설계안의 장단점 비교 완료
✅ 각 옵션의 구현 난이도 분석 완료
✅ 사용자 선택: Monolith (현재 규모에 적합)
✅ 선택 결과에 따른 구현 시작
```

## 핵심

- 에이전트가 분석 → 사용자가 선택
- 선택지는 3~4개 최적
