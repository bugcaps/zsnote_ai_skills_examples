# 로그 근본 원인 분석 (서브에이전트 실행)

이 스킬은 본 대화와 분리된 서브에이전트에서 실행됩니다. 본 대화의 내용은 보이지 않으므로, 아래 지시와 인자만으로 작업합니다.

분석할 로그: `$ARGUMENTS`

## 작업 순서

1. 인자로 받은 로그 경로가 없거나 파일이 없으면, 분석하지 않고 보고 양식의 `상태: 확인 필요`로 그 사실만 반환합니다.
2. `python ${CLAUDE_SKILL_DIR}/scripts/parse_logs.py <로그> --level ERROR`로 첫 ERROR 시각을 찾습니다.
3. `python ${CLAUDE_SKILL_DIR}/scripts/parse_logs.py <로그> --around "<첫 ERROR 시각>" --minutes 10`으로 타임라인을 추출합니다. 로그 원문은 읽지 않습니다.
4. 출력의 `최초 이벤트`가 첫 ERROR보다 앞선 WARN인지 확인하고, 가설 2개 이상을 타임라인의 줄로 지지·반박합니다.
5. 아래 보고 양식으로만 반환합니다.

## 핵심 규약

- 근본 원인에는 근거가 된 타임라인 줄을 그대로 인용합니다. 인용할 줄이 없으면 "추정"으로 표기합니다.
- 타임라인에 없는 사실은 쓰지 않습니다. 필터 밖이라 알 수 없는 것은 "미확인"으로 남깁니다.
- 시간대를 알 수 없으면 "시간대 미상"이라고 적습니다.
- 파일을 만들거나 고치지 않습니다.

## 보고 양식

```text
상태: 완료 / 실패 / 확인 필요
근본 원인: <한 줄> (근거 인용 또는 "추정")
타임라인: <스크립트 출력의 타임라인 줄 그대로>
기각한 가설: <가설 — 이유>
미확인: <필터 밖이라 알 수 없는 것. 없으면 "없음">
재발 방지: <설정값·알림 조건 같은 행동>
```

## 체크리스트

- [ ] 보고에 인용한 줄이 모두 스크립트 출력에 있다
- [ ] 보고 양식의 여섯 항목만 반환했다
