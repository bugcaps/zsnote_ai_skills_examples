# 항목별 출처 규칙

SKILL.md 의 핵심 규약만으로 "이 칸을 내가 써도 되는가"가 판단되지 않을 때 읽습니다.

## 등급 세 가지

| 등급 | 뜻 |
| :--- | :--- |
| `창작 허용` | 문장을 새로 씁니다. 단, 근거가 되는 사실은 모두 자료에 있어야 합니다. 근거가 없는 요소는 **자리표시자를 넣지 않고 생략**합니다. |
| `자료 고정` | 자료의 문구·숫자를 그대로 옮깁니다. 근거를 찾지 못하면 `[확인 필요: 항목]`으로 남깁니다. |
| `미제공 시 자리표시자 필수` | 자료에 있을 수 없는 항목입니다. 사람이 채워야 하므로 추측하지 않고 자리표시자로 둡니다. |

## 표 1 — 보도자료 항목별 규칙

| 항목 | 등급 | 이유 |
| :--- | :--- | :--- |
| 헤드라인 | `창작 허용` | 기자의 눈을 잡는 것이 목적이므로 표현은 새로 만들되, 담는 사실은 자료에서만 가져옵니다. 자료가 쓰지 않은 제품 범주와 시장 평가는 넣지 않습니다. |
| 부제 | `창작 허용` | 헤드라인이 못 담은 사실을 한 줄 더 얹는 칸입니다. 새 사실을 만드는 칸이 아닙니다. |
| 발신지·발신일 | `미제공 시 자리표시자 필수` | 배포 시점과 엠바고는 홍보 담당이 정합니다. 오늘 날짜로 채우지 않습니다. 둘을 한 항목으로 보고 `[확인 필요: 발신지·발신일]` **하나로 셉니다**. |
| 리드 | `창작 허용` | 누가·무엇을·언제·어디서·왜를 한 문단으로 압축합니다. 다섯 요소 중 자료에 근거가 없는 것은 쓰지 않고 생략합니다. `창작 허용` 등급이므로 자리표시자를 넣지 않습니다. |
| 본문 | `창작 허용` | 문장 구성과 순서는 자유입니다. 본문 안의 숫자·날짜·직함은 `자료 고정`으로 취급합니다. 기능명·사양은 `자료 고정`이지만 그 기능을 설명하는 문장은 새로 써도 됩니다. 단 자료에 없는 동작·대상·조건을 추가하지 않습니다. |
| 인용문 | `자료 고정` | 실존 인물의 발언입니다. 회사가 승인하지 않은 문장을 넣으면 정정 보도로 이어집니다. |
| 회사 소개 | `자료 고정` | 설립 연도, 사업 영역, 수치가 든 정형 문단(보일러플레이트)입니다. 회사가 쓰는 문구가 이미 있습니다. |
| 미디어 문의 | `자료 고정` | 담당자 이름·부서·연락처입니다. 없으면 `[확인 필요: 미디어 문의 담당자]`로 남깁니다. |
| 끝 표시 | `자료 고정` | 배포 관례상 `###` 한 줄로 고정합니다. 자료에 없어도 자리표시자를 쓰지 않는 유일한 항목입니다. |

## 표 2 — 제품 소개서(한 장) 항목별 규칙

| 항목 | 등급 | 이유 |
| :--- | :--- | :--- |
| 제품명 | `자료 고정` | 표기법(띄어쓰기, 영문 대소문자)까지 자료와 같아야 합니다. |
| 한 줄 정의 | `창작 허용` | 읽는 사람이 30초 안에 이해할 문장으로 다시 씁니다. 자료가 제품 범주를 밝히지 않았다면 범주를 지어내지 않고 기능으로 설명합니다. |
| 고객 문제 | `창작 허용` | 자료가 지목한 문제를 고객의 말로 풀어 씁니다. 새 문제를 발명하지 않습니다. |
| 해결 방식 | `창작 허용` | 기능을 나열하지 않고 문제와 연결해 설명합니다. |
| 주요 기능 | `자료 고정` | 기능명과 사양은 자료에 있는 것만 씁니다. 각 기능의 설명 문장은 새로 써도 됩니다. |
| 가격·요금제 | `자료 고정` | 영업 현장에서 그대로 인용되는 숫자입니다. 할인율, 부가세 포함 여부도 자료 표기를 따릅니다. |
| 고객 사례·수치 | `자료 고정` | 도입 고객사명과 성과 수치는 고객사 동의가 필요합니다. 없으면 `[확인 필요: 고객 사례]`로 남깁니다. |
| 도입 문의 | `미제공 시 자리표시자 필수` | 영업 담당 채널은 팀 사정에 따라 달라집니다. |

## 숫자와 날짜 세부 규칙

- 자료에 연도가 없으면 연도를 보충하지 않고 자료 표기를 그대로 씁니다("9월 22일"은 "9월 22일"로).
- 자료에 있는 항목을 세어 만든 개수 표현은 허용합니다("기능 두 가지"). 세는 대상이 모두 자료에 적혀 있어야 합니다.
- 비율, 배수, 단위 변환, 반올림처럼 자료의 숫자를 가공한 값은 쓰지 않습니다.

## 금지 표현

근거 자료가 함께 제공되지 않았다면 아래 표현을 쓰지 않습니다.

- **최상급**: 업계 최초, 국내 1위, 최대 규모, 가장 저렴, 유일한
- **비교**: 경쟁 제품보다 빠른, 타사 대비 우수한 (비교 시점·조건·출처가 없는 경우)
- **속 빈 형용사**: 혁신적인, 획기적인, 차별화된, 압도적인, 완벽한
- **근거 없는 수식**: 많은 고객이, 폭발적인 반응, 빠르게 성장하는

최상급·비교 표현을 자료에서 찾았더라도, 초안 끝에 "법무·홍보팀 검토가 필요한 표현"으로 따로 모아 알립니다.

## 등급을 나눈 예 (가상 사례)

가상의 서비스 '피크플로우'가 새 기능을 내놓는 상황입니다. 자료에는 다음 세 줄만 있습니다.

```text
- 피크플로우, 9월 30일 '주간 리포트 자동 발송' 기능 공개
- 기능: 지정한 요일에 팀 활동 요약을 메일로 보냄
- 대표: 정하윤 (발언 없음)
```

인용문 칸(`자료 고정`)

```text
나쁜 초안
  정하윤 피크플로우 대표는 "팀의 소통 방식을 바꾸겠다"라고 말했다.
  → 자료에 없는 발언입니다. 직함이 맞더라도 문장을 지어낸 것이므로 쓸 수 없습니다.

좋은 초안
  [확인 필요: 대표 인용문 — 승인 문구 필요]
  → 자리표시자로 남기고, 초안 끝에 "자리표시자 1개: 대표 인용문"으로 보고합니다.
```

헤드라인 칸(`창작 허용`)

```text
나쁜 초안
  피크플로우, 업계 최초 리포트 자동화로 협업 도구 시장 판도를 바꾼다
  → "업계 최초"는 근거가 없고, "협업 도구"는 자료에 없는 제품 범주이며,
    "판도를 바꾼다"는 자료에 없는 평가입니다. 창작 허용 칸에서도 막힙니다.

좋은 초안
  피크플로우, 팀 활동 요약을 메일로 보내는 '주간 리포트 자동 발송' 9월 30일 공개
  → 표현은 새로 썼지만 기능명·동작·날짜가 모두 자료 안에 있고, 연도를 붙이지 않았습니다.
```
