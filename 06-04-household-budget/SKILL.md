# 가계 지출 집계

명세서 원본을 대화에 붙여 넣지 않습니다. **스크립트가 원본을 읽고 범주별 합계만 내보내면** 같은 분석을 하면서도 가맹점명·카드번호·거래 시각은 대화에 남지 않습니다. 파일이 커서 스크립트를 쓰는 것이 아니라, 남기고 싶지 않아서 씁니다.

## 작업 순서

1. **파일 경로만 받습니다.** 사용자가 명세서 내용을 채팅에 붙여 넣으려 하면 파일로 저장한 뒤 경로를 달라고 안내합니다. **원본 파일을 직접 열지 않습니다.** 첫 줄만 훑는 것도 여는 것이고, 열 이름은 스크립트가 알려 주는 것만 씁니다.
2. **한 줄로 실행합니다.** `python scripts/summarize_spending.py <파일경로>`
3. **열 이름이 안 맞으면 지정해 다시 실행합니다.** 열 이름은 카드사마다 다릅니다. 스크립트가 종료 코드 1과 함께 열 이름을 알려 주면 `--date-col`·`--merchant-col`·`--amount-col`로 지정해 다시 돌립니다. "첫 줄이 거래 한 건으로 보인다"고 하면 지정할 이름 자체가 없는 파일이므로, 사용자에게 첫 줄에 열 이름을 적어 넣어 달라고 안내합니다. 비어 있는 결과를 그대로 보고하지 않습니다.
4. **`읽지 못한 행`을 먼저 봅니다.** 0이 아니면 그 건수를 보고서 맨 앞에 적고 사용자에게 알립니다. 종료 코드가 1이면 "지출이 없습니다"가 아니라 "집계하지 못했습니다"입니다.
5. **달을 비교할 때는 `--month`로 두 번 실행합니다.** `--month 2026-08`과 `--month 2026-07`의 범주별 합계를 나란히 놓고 차액을 적습니다. 범주별 비교는 이 방법으로만 하고, 한 번 실행했을 때 나오는 `[월별 합계]` 블록은 총액 확인용으로만 씁니다. 비교표를 쓰기 전에 두 실행의 `[기간]` 줄을 맞대어 보고, 포괄 기간이 다르면(한쪽이 며칠치뿐이면) 증감을 말하기 전에 그 사실을 먼저 적습니다. 한쪽 달에만 있는 범주는 `0원`이 아니라 `집계 없음`으로 적습니다.
6. **보고서를 씁니다.** `기간 · 집계한 행/읽지 못한 행 · 범주별 합계표 · 미분류` 순서로 쓰고, 스크립트가 출력하지 않은 숫자는 적지 않습니다.

산출물은 사용자가 지정한 폴더에 저장하고, 지정이 없으면 별도의 작업 폴더를 만들어 씁니다. **이 스킬 폴더 안에는 새 파일을 만들지 않고 `data/`의 샘플도 고치지 않습니다**(동봉된 연습용 샘플입니다).

## 핵심 규약

- **스크립트 출력 밖의 원본을 대화에 올리지 않습니다.** 예외는 미분류 가맹점명 하나뿐입니다. 사용자가 분류를 고쳐야 하므로 금액이 큰 순으로 **최대 5개**까지만 옮기고 나머지는 `외 N곳`으로 적습니다. 개별 거래의 날짜·금액은 적지 않습니다.
- **카드번호·계좌번호는 뒤 네 자리만 남깁니다.** 사용자가 가리지 않은 번호를 보내 왔더라도 그대로 되풀이하지 않습니다.
- **`0원`과 `집계 못 함`을 같은 말로 쓰지 않습니다.** 열 이름이 안 맞아 한 행도 못 읽은 것과 정말 지출이 없는 것은 다릅니다. 종료 코드 1은 언제나 `집계 못 함`입니다.
- **읽지 못한 행을 숨기지 않습니다.** 금액 칸에 `승인대기` 같은 글자가 섞이면 그 행은 합계에서 빠집니다. 건수를 적지 않으면 사용자는 빠진 줄을 알 수 없습니다.
- **읽은 인코딩을 보고서에 적습니다.** 국내 카드사 CSV는 `cp949`가 흔해서 스크립트가 `읽은 인코딩` 줄에 무엇으로 읽었는지 출력합니다. 가맹점명이 깨져 보이면 집계를 믿지 말고 다시 내려받도록 안내합니다.
- **합계는 환불·취소를 뺀 순액입니다.** 음수 행의 건수가 함께 출력되므로 합계 옆에 같이 적습니다.
- **범주는 스크립트의 `CATEGORY_RULES` 한 곳에서만 정합니다.** 보고서에서 범주를 새로 만들거나 이름을 바꾸지 않고, 분류를 고칠 때는 키워드를 추가한 뒤 다시 실행합니다.
- **금융 조언과 절약 권유를 하지 않습니다.** 투자·대출·보험·절세를 권하지 않고, "이 지출을 줄이세요" 같은 권유는 곁들이지도 않습니다. 늘고 준 금액을 숫자로 보여 주는 데서 멈추고, 무엇을 줄일지는 사용자가 정합니다.

## 체크리스트

보고서를 내보내기 전에 확인하고, 하나라도 어긋나면 고친 뒤 보고합니다.

- [ ] 원본 CSV를 직접 열지 않았다(스크립트에만 넘겼다)
- [ ] 명세서 원본 내용이 대화에 올라오지 않았다(미분류 가맹점명 최대 5개 외)
- [ ] `집계한 행`과 `읽지 못한 행`을 둘 다 보고서에 적었다
- [ ] 종료 코드 1을 "지출이 없습니다"로 바꿔 쓰지 않았다
- [ ] 열 이름 매칭 줄과 읽은 인코딩을 확인해 적었다
- [ ] 카드번호·계좌번호가 뒤 네 자리만 남아 있다
- [ ] 범주 이름이 스크립트 출력과 같고, 새로 만든 범주가 없다
- [ ] 환불·취소 건수를 합계와 함께 적었다
- [ ] 투자·대출·절약 권유가 없다
- [ ] 산출물을 이 스킬 폴더 밖에 저장했다
