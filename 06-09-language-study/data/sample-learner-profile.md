# 학습 프로필 — 영어

테스트용으로 지어낸 프로필입니다. 실존 인물과 무관하며, 열두 번의 교정을 거친 상태로 채워 두었습니다.
연습할 때는 이 파일을 고치지 말고 작업 폴더에 복사해서 쓰세요.
