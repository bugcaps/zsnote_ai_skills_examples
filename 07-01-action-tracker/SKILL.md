# 회의 액션 아이템 누적

앞 스킬의 회의록을 **고치지 않고 읽기만** 해서, 액션 표의 행을 `회의날짜-번호` 식별자를 붙여 할 일 목록에 옮깁니다. 목록에 쓰는 일은 스크립트가 하고, 에이전트는 입력을 찾고 결과를 전합니다.

## 작업 순서

1. **회의록을 찾습니다.** 사용자가 경로를 주면 그 파일을, 아니면 작업 폴더의 `회의록-*.md`를 찾습니다. 여러 개면 목록을 보여 주고 고르게 합니다. 회의록이 없으면 meeting-notes-summarizer로 먼저 회의록을 만들라고 안내하고 멈춥니다.
2. **미리보기를 돌립니다.** `python ${CLAUDE_SKILL_DIR}/scripts/merge_actions.py "<회의록>"`. 파일은 바뀌지 않습니다.
3. **`[중단]`이면 메시지대로 처리합니다.** 회의 날짜가 없다는 메시지면 사용자에게 날짜를 물어 `--date YYYYMMDD`를 붙입니다. 실행한 날짜로 대신 채우지 않습니다. 형식 표시가 없다는 메시지면 고치지 말고 그대로 보고합니다.
4. **같은 명령에 `--apply`를 붙여 씁니다.** 할 일 목록은 회의록과 같은 폴더의 `할일목록.md`입니다(없으면 스크립트가 만듭니다).
5. **보고합니다.** `추가 / 이미 있음 / 확인 필요` 세 숫자, 추가된 식별자, 할일목록 경로를 적습니다.

## 핵심 규약

- **회의록에 없는 할 일을 더하지 않습니다.** 액션 표의 행만 옮기며, 보류·결정을 할 일로 바꾸지 않습니다.
- **`[TODO: …]`는 그대로 둡니다.** 담당자나 기한을 추측해 채우지 않습니다.
- **할일목록과 회의록을 손으로 고치지 않습니다.** 쓰는 일은 스크립트만 하며, 기존 행(사람이 바꾼 `상태` 포함)은 스크립트도 고치지 않습니다.
- **식별자가 겹치면 넣지 않습니다.** 같은 회의록을 두 번 넣어도 목록이 늘지 않아야 정상입니다.

## 체크리스트

- [ ] 미리보기를 먼저 돌렸다
- [ ] 회의 날짜를 사용자 확인 없이 채우지 않았다
- [ ] 보고한 세 숫자가 스크립트 출력과 같다
- [ ] 회의록 파일이 바뀌지 않았다
