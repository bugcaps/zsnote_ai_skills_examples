# 파워포인트(PPT) 자동 문서화

에이전트는 **무엇을 말할지**만 정합니다. 어떻게 보일지는 Marp 테마와 변환 스크립트가 맡습니다.

## 작업 순서

1. 원고나 주제를 도입·본론·결론으로 나누고 슬라이드별 핵심 메시지를 한 줄로 정합니다.
2. Marp 마크다운으로 작성합니다. 파일 맨 위에 `marp: true` 프론트매터를 두고, `---`로 슬라이드를 나눕니다.
3. **구조 검사**: 파일로 저장한 뒤 `python scripts/generate_pptx.py <파일> --check`를 실행합니다. 제목 누락과 불릿 초과를 잡아 줍니다. 문제가 있으면 고치고 다시 실행합니다.
4. `.pptx` 파일을 요청받은 경우에만 `python scripts/generate_pptx.py <파일> <출력.pptx>`를 실행합니다. **종료 코드 3은 `python-pptx` 미설치**라는 뜻이므로, 설치 명령을 안내하고 마크다운을 그대로 전달합니다.
5. 마크다운 본문과 검사 결과를 함께 보고합니다.

## 핵심 규약

- **슬라이드 하나에 불릿 4개까지.** 넘으면 슬라이드를 나눕니다. 문장이 아니라 구(句)로 씁니다.
- 원고에 없는 수치를 만들지 않습니다. 근거가 없는 자리는 `[확인 필요]`로 둡니다.
- 테마는 Marp 기본 테마(`default`, `gaia`, `uncover`)만 씁니다. CSS를 직접 작성하지 않습니다.
- 표·다단·차트는 넣지 않습니다. 필요하면 마크다운 이미지 자리만 잡고 사람에게 넘깁니다.

## 체크리스트

- [ ] 프론트매터에 `marp: true`가 있다
- [ ] `--check`를 실행했고 문제 0건이다
- [ ] 슬라이드마다 제목이 있고 불릿이 4개 이하다
- [ ] 원고에 없는 수치를 지어내지 않았다
