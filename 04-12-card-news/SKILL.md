# SNS 카드뉴스 레이아웃 기획

디자인이 아니라 **배치 명세**를 만듭니다. 결과물은 디자이너가 그대로 작업에 들어갈 수 있는 수치여야 합니다.

## 작업 순서

1. **플랫폼 확인**: 어느 플랫폼인지 묻거나 확정합니다. `references/card-news-guide.md`에서 해당 규격과 안전 여백을 읽습니다.
2. **원고 분절**: 글자 수를 세어 타이틀 15자, 서브 30자 제한과 대조합니다. 넘으면 압축안을 제시하거나 여러 장으로 나눕니다. **원본 문장과 압축안을 나란히 보여 줍니다.**
3. **영역 배치**: 아래 표 형식으로 출력합니다. 비율(%)과 픽셀을 함께 적습니다.

```text
| 영역 | 위치(%) | 픽셀 | 내용 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 타이틀 | 상단 12~30% | y 130~324 | "초경량 990g 출시" (12자) | |
| 메인 이미지 | 중앙 32~78% | y 346~842 | 제품 컷 | |
| 안전 여백 | 하단 15% | y 918~1080 | 비움 | UI 겹침 방지 |
```

4. 체크리스트로 점검한 뒤, 장수와 각 장의 역할을 요약해 보고합니다.

## 핵심 규약

- **픽셀 값은 계산해서 적습니다.** "적당한 여백" 같은 표현을 쓰지 않습니다.
- 안전 여백 영역에는 텍스트·로고를 배치하지 않습니다. 비워 두는 이유를 비고에 적습니다.
- 글자 수는 실제로 세어 괄호에 표기합니다. 제한을 넘으면 넘었다고 밝힙니다.
- 색상·폰트를 지정하지 않습니다. 브랜드 규칙은 [04-2 브랜드 검수](../04-2-brand-guide/SKILL.md)와 [04-5 컬러·타이포](../04-5-color-typo/SKILL.md)가 담당합니다.
- 이미지를 생성하지 않습니다. 이미지 자리는 영역과 설명으로만 지정합니다.

## 체크리스트

- [ ] 플랫폼과 해상도를 명시했다
- [ ] 모든 영역에 비율(%)과 픽셀 값이 있다
- [ ] 타이틀·서브 글자 수를 세어 표기했다
- [ ] 안전 여백 영역이 비어 있다
- [ ] 원고가 길면 압축안을 원본과 함께 제시했다
