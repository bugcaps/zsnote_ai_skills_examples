# 프롬프트 기반 이미지 생성

프롬프트 작성은 에이전트가, 호출과 저장은 스크립트가 합니다. **돈이 나가는 호출이므로 사용자 확인 없이 실행하지 않습니다.**

## 작업 순서

1. **프롬프트 확장**: 요청에서 피사체·배경·조명·스타일·화면비를 뽑아 영문 프롬프트로 만듭니다. 사용자가 말하지 않은 요소는 보완하되, 무엇을 보완했는지 한국어로 함께 알립니다.
2. **예상 비용 확인**: `python scripts/generate_image.py --prompt "<프롬프트>" --output <파일> --dry-run`을 실행합니다. 네트워크를 쓰지 않고 요청 내용과 예상 비용만 출력합니다.
3. **사용자 확인**: 프롬프트와 비용을 보여주고 **생성해도 되는지 묻습니다.** 승낙 없이 4단계로 넘어가지 않습니다.
4. **생성**: `--dry-run` 없이 같은 명령을 실행합니다. `OPENAI_API_KEY`가 없으면 여기서 멈추고 사용자에게 알립니다.
5. **보고**: 저장 경로, 최종 영문 프롬프트, API가 프롬프트를 수정했다면 그 내용을 함께 전달합니다.

## 핵심 규약

- **한 요청에 한 장만 생성합니다.** 여러 장이 필요하면 장수와 비용을 먼저 확인받습니다.
- 실존 인물, 특정 브랜드 로고, 저작권이 있는 캐릭터를 프롬프트에 넣지 않습니다. 요청받으면 거절 사유를 설명합니다.
- 스크립트가 실패하면 **성공했다고 보고하지 않습니다.** 파일이 만들어지지 않았음을 그대로 전달합니다.
- 생성 실패를 다른 프롬프트로 바꿔 가며 반복 재시도하지 않습니다. 2회 실패하면 멈추고 보고합니다.

## 체크리스트

- [ ] `--dry-run`으로 비용을 먼저 확인했다
- [ ] 생성 전에 사용자 승낙을 받았다
- [ ] 보완한 프롬프트 요소를 한국어로 설명했다
- [ ] 스크립트 종료 코드로 성공·실패를 판단했다 (파일 존재 여부 확인)
- [ ] 실존 인물·브랜드·저작권 캐릭터가 프롬프트에 없다
