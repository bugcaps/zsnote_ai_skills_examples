# 답장 갈래 판정 규약

## 세 갈래

| 갈래 | 뜻 | 초안 | 이 갈래로 보내는 때 |
| :--- | :--- | :--- | :--- |
| `답장 필요` | 상대가 회신을 기다리고 있고, 사실 확인이나 짧은 응답으로 끝난다 | **쓴다** | 질문·요청·일정 조율·참석 회신처럼 답이 없으면 상대의 일이 멈추는 메일 |
| `읽고 넘김` | 읽어 두면 되고 답장이 없어도 아무 일도 멈추지 않는다 | 쓰지 않는다 | 전체 공지, 자동 발송 알림·영수증, 회신 불가 주소, "회신 불필요"라고 적힌 메일 |
| `사람이 직접 써야 함` | 답장은 필요하지만 문장을 사람이 직접 써야 한다 | **쓰지 않는다** | 아래 "사람이 직접 써야 하는 주제" 목록에 걸리는 메일 |

세 갈래 밖의 이름을 만들지 않습니다. 한 메일은 한 갈래에만 들어갑니다.

## 판정 순서

메일 한 통마다 아래 순서를 그대로 밟습니다. **순서를 바꾸면 사과해야 할 메일에 초안이 붙습니다.**

1. **"사람이 직접 써야 하는 주제" 목록에 걸리는가?** 걸리면 다른 조건을 보지 않고 `사람이 직접 써야 함`입니다. 그 메일이 질문을 담고 있어도 마찬가지입니다. **목록이 언제나 이깁니다.**
2. **상대가 회신을 기다리는가?** 질문·요청·확인·일정 조율이 있으면 `답장 필요`입니다.
3. **둘 다 아니면** `읽고 넘김`입니다.
4. **어느 갈래인지 망설여지면 `사람이 직접 써야 함`입니다.** 초안을 만들지 않는 쪽이 언제나 덜 위험합니다.

## 사람이 직접 써야 하는 주제

| 주제 | 예 | 초안을 만들면 생기는 일 |
| :--- | :--- | :--- |
| 사과 | 누락·지연·오류에 대한 항의, 불만 접수 | 사과의 무게와 책임 범위를 에이전트가 정하게 됩니다 |
| 거절 | 제안·요청·초대를 거절해야 하는 메일 | 관계가 걸린 표현을 사람이 고르지 못한 채 나갑니다 |
| 협상 | 단가·기한·범위 조정 요청 | 양보 가능한 선이 초안에 먼저 적히고 그대로 보내집니다 |
| 급여·처우 | 연봉, 인사 평가, 채용 조건 | 되돌릴 수 없는 개인 조건이 문장으로 확정됩니다 |
| 계약·법률 | 계약 조항, 해지, 분쟁, 법적 통보 | 문장 하나가 책임을 만듭니다 |
| 금전·계좌 | 송금 요청, 계좌 변경 안내, 결제 확인 요구 | 사칭 메일에 확인 답장을 보내 피해가 시작됩니다 |
| 인사·신상 | 징계, 퇴사, 건강·가족 사정 | 사람 사이의 일을 에이전트 문체로 다루게 됩니다 |

이 목록은 "이 메일에 답하지 말라"는 뜻이 아니라 **"문장을 에이전트가 쓰지 말라"**는 뜻입니다. 사용자에게는 무엇을 정하고 써야 하는지만 알려 줍니다. 예: `무엇을 사과할지, 보상 범위를 어디까지 약속할지 정하신 뒤 직접 쓰십시오.`

## 분류표 양식

초안보다 먼저 이 표를 내보냅니다.

| 번호 | 보낸 사람(역할) | 제목 | 갈래 | 그렇게 본 이유 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | {{ 역할명 }} | {{ 원문 제목 }} | {{ 세 갈래 중 하나 }} | {{ 그렇게 판정한 근거를 한 줄로 }} |

표 아래에 합계 한 줄을 적습니다.

`읽은 메일 {{ N }}통 = 답장 필요 {{ }} + 읽고 넘김 {{ }} + 사람이 직접 써야 함 {{ }} · 초안 {{ }}건 · 읽지 못한 메일 {{ N통 또는 확인 못 함 }}`

읽지 못한 메일은 갈래에 넣지 않고 이 줄의 마지막 항목으로만 셉니다. 갈래 합계에 섞으면 읽어 본 메일과 못 읽은 메일이 구분되지 않습니다.

마지막 항목은 아래 셋 중 하나로 적고, 칸을 비우거나 항목을 지우지 않습니다.

| 표기 | 뜻 |
| :--- | :--- |
| `N통` | 읽지 못한 메일이 몇 통인지 확인했다 |
| `0통` | 못 읽은 메일이 없다는 것을 **실제로 확인했다** |
| `확인 못 함` | 메일함에 닿지 못해 몇 통이 있는지조차 모른다 |

메일 읽기 도구가 없고 사용자가 개수를 알려 주지도 않았다면 `확인 못 함`입니다. 이때 `0통`으로 적으면 못 읽은 메일이 없다는 거짓말이 됩니다.

## 초안 양식

`답장 필요` 갈래에만 씁니다.

```
### 초안 1 — [원문 제목]
받는 사람: (원문의 보낸 사람 역할)
제목: Re: [원문 제목]

(본문. 상대가 물은 것에만 답합니다. 원문에 없는 날짜·금액·승낙은 쓰지 않습니다.)

확인이 필요한 항목
- [TODO: 확인] {{ 원문에 없어 사람이 채워야 하는 항목 }}
```

- 원문이 존댓말이면 존댓말로, 사내 메일이면 간결하게 맞춥니다. 원문에 없는 친근한 인사말을 지어내지 않습니다.
- 상대가 묻지 않은 정보를 덧붙이지 않습니다. 답장이 길어질수록 사람이 검토하지 않고 보냅니다.
- 초안에 파일을 첨부하지 않습니다. 첨부가 필요하면 `[TODO: 확인]` 항목으로만 남기고 파일을 찾아 나서지 않습니다.
- 초안 끝에 `— 보내기 전에 사람이 확인하십시오.` 한 줄을 붙입니다.

## 연습용 샘플

`data/sample-inbox.md`는 세 갈래가 모두 나오도록 지어낸 **가상 받은 편지함**입니다. 실존 인물·회사·메일 주소와 무관하며, 주소는 모두 `example.invalid` 도메인입니다. 실제 메일로 쓰지 않고 파일을 고치지도 않습니다.
