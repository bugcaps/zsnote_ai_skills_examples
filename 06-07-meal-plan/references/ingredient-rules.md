# 재료 이름·단위·합산 규칙

재료를 세고 더하는 규칙은 이 파일에만 있습니다. 식단표·장보기 목록에는 결과만 적고 규칙을 다시 적지 않습니다.

## 1. 같은 재료로 보는 기준

합산의 키는 **재료 이름**입니다. 이름이 같은 것끼리만 더합니다.

아래 별칭 표에 있는 쌍은 왼쪽 이름으로 통일해 합산합니다. **표에 없는 이름은 비슷해 보여도 합치지 않습니다.**

| 대표 이름 | 같은 것으로 보는 이름 |
| :--- | :--- |
| 대파 | 파 |
| 달걀 | 계란 |
| 양파 | 둥근파 |
| 애호박 | 호박(애호박이라고 적힌 요리가 있을 때만) |
| 식용유 | 기름(식용유라고 적힌 요리가 있을 때만) |

합치지 않는 예:

- **쪽파·실파는 대파와 다른 재료입니다.** 크기와 쓰임이 다릅니다.
- **부위가 다른 고기는 다른 재료입니다.** 삼겹살·목살·앞다리살을 `돼지고기`로 묶지 않습니다.
- **가공 상태가 다르면 다른 재료입니다.** 다진 마늘과 통마늘, 생새우와 냉동새우는 각각 셉니다.
- 별칭 표에 넣을지 망설여지면 **합치지 않고** 두 행으로 두며, 두 행 모두에 `나온 요리` 번호를 적습니다.

## 2. 단위 계열

| 계열 | 단위 |
| :--- | :--- |
| 무게 | g, kg |
| 부피 | ml, L, 컵, 큰술, 작은술 |
| 낱개 | 개, 대, 쪽, 모, 장, 마리, 봉, 봉지, 팩, 단 |

**같은 계열 안에서만 환산합니다.**

- 무게: `1kg = 1000g`. g으로 모아 더하고, 1000g 이상이면 kg으로 적습니다.
- 부피: `1L = 1000ml`, `1컵 = 200ml`, `1큰술 = 15ml`, `1작은술 = 5ml`. ml로 모아 더한 뒤 원래 가장 많이 쓰인 단위로 되돌립니다.
- 낱개: `개`·`대`·`쪽`처럼 서로 다른 낱개 단위는 **같은 계열이어도 환산하지 않습니다.** 재료마다 뜻이 달라서입니다.

**계열이 다른 단위는 환산하지 않습니다.** `양파 1개`가 몇 g인지는 크기에 따라 다르고, 그 숫자는 기억에서 나옵니다. 계열이 섞인 재료는 한 행 안에 계열별 소계를 `+`로 이어 적고 `단위 혼합`으로 표시합니다.

```
양파 | 2개 + 150g | 단위 혼합
```

사는 사람이 보고 판단하도록 남겨 두는 것이며, 하나의 숫자로 합치지 않습니다.

**위 표에 없는 단위는 그 단위 하나가 곧 하나의 계열입니다.** `공기`, `인분`, `줌`, `조각`처럼 계량 단위가 아닌 말은 같은 단위끼리만 더하고 무엇으로도 환산하지 않습니다. `밥 3공기 + 밥 2공기 = 밥 5공기`이며, 공기를 g으로 바꾸지 않습니다. 숫자가 붙어 있으면 분량이 있는 것으로 봅니다.

**숫자가 없는 표현은 분량이 아닙니다.** `약간`, `조금`, `적당량`, `기호에 따라`는 분량 미상으로 다룹니다(아래 4절).

## 3. 분수와 반올림

- 분수는 소수로 바꿔 더합니다. `1/2대`가 세 번이면 `1.5대`입니다. `2대`로 올리지 않습니다.
- 나누어떨어지지 않는 값은 **소수 둘째 자리에서 반올림**하고 행 끝에 `≈`를 붙입니다. `1/3컵`이 두 번이면 `0.67컵 ≈`입니다.
- 결과가 정수면 소수점을 붙이지 않습니다. `1.0대`가 아니라 `1대`입니다.
- **필요량을 구매 단위로 바꾸지 않습니다.** `대파 1.5대`를 `대파 한 단`으로 적지 않습니다. 파는 단위는 가게마다 다르고, 무엇을 살지는 사람이 정합니다.

## 4. 값이 없거나 읽히지 않을 때

집에 있는 양은 식단표의 `집에 있는 것` 표에서 읽습니다.

| 상황 | 처리 |
| :--- | :--- |
| 분량이 적혀 있지 않음 | 0으로 세지 않습니다. 같은 재료의 합산값 뒤에 `+ 분량 미상 N회`를 적고, 그 행을 `사람이 확인할 것`으로 내립니다 |
| 재료 이름을 알아볼 수 없음 | 고쳐 쓰거나 비슷한 이름으로 바꾸지 않습니다. **원문 그대로** 옮기고 `판독 불가`로 표시해 `사람이 확인할 것`에 둡니다. 이름을 모르면 제한 대조도 할 수 없습니다 |
| 이름만으로 성분을 알 수 없음(소스·양념장·가공식품) | `성분 확인 필요`로 표시해 `사람이 확인할 것`에 둡니다 |
| 집에 있는 양을 사용자가 말했으나 수치가 없음("좀 있어") | 빼지 않습니다. `살 것`에 필요량 전부를 두고 `집에 있다고 함(양 미상)`을 적습니다 |
| 집에 있는 양이 필요량보다 적음 | 부족분만 `살 것`에 적고 같은 행에 `필요 3개 − 집 1개 = 2개`처럼 뺄셈을 남깁니다 |
| 집에 있는 양의 단위 계열이 필요량과 다름(필요 `2큰술` / 집에 `500g 통 반쯤`) | **빼지 않습니다.** `살 것`에 필요량 전부를 두고 `집 재고 단위 다름`을 적습니다. 계열이 다른 단위를 환산하지 않는다는 2절의 규칙은 재고를 뺄 때도 같습니다 |

`사람이 확인할 것`으로 내린 행도 **가짓수와 등장 수 대조에는 그대로 셉니다.** 대조에서 빠지면 없어진 것과 같습니다.
