# SNS 플랫폼별 작성 가이드

## 인스타그램 (Instagram)
- **어조**: 친근하고 감성적이며, 시각적 요소를 돋보이게 하는 설명. 적절한 이모지 사용 필수.
- **길이**: 첫 2~3줄에서 시선을 사로잡아야 함. 총 150~300자 내외 권장.
- **구조**: 시선 끌기 -> 본론 -> 행동 유도(프로필 링크 클릭 등). 줄바꿈을 활용해 가독성 확보.
- **해시태그**: 5~10개 권장. 글 하단에 배치하며, 트렌디한 키워드와 구체적인 키워드를 섞어 사용.

## 링크드인 (LinkedIn)
- **어조**: 전문적, 논리적, 비즈니스 중심. 통찰력과 배움을 공유하는 태도.
- **길이**: 300~500자 권장. 첫 줄은 제목처럼 명확하게 작성.
- **구조**: 문제 제기/훅 -> 개인적 인사이트/경험 -> 배운 점/결론 -> 질문으로 소통 유도.
- **해시태그**: 3~5개 권장. 본문 하단에 배치하며 포괄적인 산업/직무 관련 키워드 사용.

## X (Twitter)
- **어조**: 간결하고 재치 있으며 즉각적인 반응을 유도하는 스타일.
- **길이**: 280자 제한(영문 기준, 한글은 더 짧게 느껴짐). 가능한 짧게 핵심만 전달.
- **구조**: 하나의 핵심 메시지 혹은 스레드(타래) 형태를 유도하는 훅. 
- **해시태그**: 1~2개 권장. 본문 문맥 속에 자연스럽게 녹이거나 끝에 간략히 첨부.
