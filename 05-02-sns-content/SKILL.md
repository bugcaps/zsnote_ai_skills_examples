# 작업 순서

1. 사용자가 제공한 원천 콘텐츠(글, URL 내용, 아이디어 등)의 핵심 메시지를 파악합니다.
2. 타겟 SNS 채널을 확인합니다. (지정하지 않은 경우 인스타그램, 링크드인, X를 기본값으로 사용합니다.)
3. `assets/platforms.md`를 참조하여 각 채널의 문법, 길이 제한, 어조, 해시태그 규칙을 숙지합니다.
4. 채널별 특성에 맞춰 원천 콘텐츠를 재가공하여 본문과 해시태그를 작성합니다.

# 핵심 규약

- **플랫폼 최적화**: 동일한 내용이라도 채널의 성격(예: 링크드인은 전문가적, 인스타그램은 감성적/시각적)에 맞게 완전히 다르게 서술해야 합니다.
- **길이 및 구조 준수**: 플랫폼별 권장 길이를 넘지 않도록 하고, 가독성을 위해 적절한 줄바꿈과 이모지를 사용합니다.
- **해시태그 전략**: 각 플랫폼에 맞는 최적의 해시태그 개수와 위치(본문 포함 또는 하단 배치)를 지킵니다.

# 체크리스트

- [ ] `assets/platforms.md`의 채널별 글자 수 및 해시태그 규칙을 준수했는가?
