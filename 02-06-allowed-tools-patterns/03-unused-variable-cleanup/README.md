# unused-variable-cleanup 사용 예시

## 요청

"미사용 변수 정리해줄래?"

## 에이전트의 동작

```
1️⃣ Grep: "const.*=" 검색
   → 50개 변수 발견

2️⃣ Read: 각 변수 사용 여부 확인
   → 8개 미사용 발견:
      - const tempData = ...
      - const unused = ...
      - etc.

3️⃣ Edit: 미사용 변수 8개 제거
```

## 산출물

```
✅ 8개 미사용 변수 제거됨
✅ 테스트 통과
✅ 번들 사이즈 감소 (~2KB)
```

## 함정

❌ 콜백 함수명이 사용 중인데 미사용으로 판단할 수 있음
✅ 이벤트 핸들러, 콜백은 수동으로 확인 후 제거
