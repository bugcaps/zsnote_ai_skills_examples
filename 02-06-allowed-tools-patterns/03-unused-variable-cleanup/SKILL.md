# unused-variable-cleanup (미사용 변수 제거)

## 작업 순서

1. **변수 목록 추출**: Grep으로 `const|let|var` 검색
2. **사용 여부 확인**: 각 변수를 Grep으로 검색 (정의 제외)
3. **미사용 항목 표시**: 검색 결과가 1개(정의만)인 항목 파악
4. **제거**: Edit으로 미사용 변수/함수/import 삭제

## 핵심 규약

- **_로 시작하는 변수는 의도적 무시**: 제거 금지 (예: `_unused`)
- **콜백 함수는 주의**: 함수명이 실제로 사용 중인 경우 다수 (Edit 전 반드시 확인)
- **타입 정의 확인** (TypeScript): 타입만 사용하는 경우 구분

## 체크리스트

- [ ] 정말 사용되지 않는가 (Grep 재확인)
- [ ] 의도적 무시 변수(_로 시작)는 제외됨
- [ ] 콜백/이벤트 핸들러는 수동으로 확인
- [ ] 삭제 후 테스트 통과
