# update-comments (주석 동기화)

## 작업 순서

1. **변경사항 파악**: Read로 어떤 코드가 변경되었는지 확인
2. **구버전 흔적 검색**: Grep으로 구버전 이름이 주석에 남아있는지 검색
3. **주석 수정**: Edit으로 구버전 참조를 신규버전으로 변경
4. **타입 주석 확인** (TypeScript): 타입도 변경되었으면 타입 주석도 수정

## 핵심 규약

- **기술 부채 방지**: "TODO", "FIXME" 주석은 그대로 두기 (의도적)
- **설명은 'WHY', 코드는 'WHAT'**: 주석에서 왜 이렇게 했는지만 설명
- **코드 변경 = 주석 검토**: 변수명/함수명 변경 시 주석도 함께 개선

## 체크리스트

- [ ] 구버전 이름이 주석에 남아있지 않음
- [ ] 함수/변수 설명이 최신 로직을 반영
- [ ] 예시 코드가 있으면 최신 버전으로 수정됨
- [ ] TODO/FIXME는 유지됨
