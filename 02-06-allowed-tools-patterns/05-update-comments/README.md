# update-comments 사용 예시

## 요청

"변수명 user → currentUser로 바꿨는데 주석도 확인해줄래?"

## 에이전트의 동작

```
1️⃣ Read: 주석 확인
   → "// user 객체를 저장합니다"

2️⃣ Grep: 주석에서 "user" 검색
   → 3곳에서 발견

3️⃣ Edit: 주석 3개 수정
   OLD: // user 객체를 저장합니다
   NEW: // currentUser 객체를 저장합니다
```

## 산출물

```
✅ 3개 주석 수정됨
✅ 변수명과 주석이 일치함
✅ 기술 부채 감소
```

## 함정

❌ TODO, FIXME 주석까지 수정하면 안 됨 (의도적 할일)
✅ 변수/함수 설명만 선택적으로 수정
