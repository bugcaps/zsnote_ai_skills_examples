# extract-magic-numbers (상수 추출)

## 작업 순서

1. **매직 넘버 검색**: Grep으로 `\d{3,}` 또는 자주 반복되는 숫자 찾기
2. **의미 파악**: Read로 해당 숫자가 뭘 의미하는지 확인 (시간, 크기, 개수 등)
3. **상수 정의**: 파일 상단에 의미 있는 이름으로 상수 정의
4. **코드 수정**: Edit으로 매직 넘버를 상수명으로 변경

## 핵심 규약

- **상수명은 명확하게**: `const ONE_HOUR_MS = 3600000` (O), `const NUM = 3600000` (X)
- **반복되는 숫자를 우선**: 1번만 쓰는 숫자는 상수화 불필요
- **시간 단위 명시**: ms, s, h를 상수명에 포함 (예: `TIMEOUT_MS`, `MAX_RETRIES`)

## 체크리스트

- [ ] 상수의 목적이 이름에서 명확함
- [ ] 시간, 크기, 개수 등 단위가 상수명에 포함됨
- [ ] 중복된 매직 넘버가 모두 상수로 변경됨
- [ ] 상수는 파일 상단 또는 설정 파일에 정의됨
