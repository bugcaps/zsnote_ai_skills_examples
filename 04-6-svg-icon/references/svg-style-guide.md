# SVG 스타일 가이드

아이콘과 로고 생성 시 반드시 준수해야 하는 디자인 시스템 규칙입니다.

## 1. 기본 설정
- **크기**: 아이콘은 `viewBox="0 0 24 24"`, 로고는 `viewBox="0 0 200 64"`를 기본으로 합니다.
- **xmlns 속성**: `<svg xmlns="http://www.w3.org/2000/svg" ...>` 를 반드시 포함합니다.

## 2. 색상 팔레트 (Brand Colors)
아이콘은 그래픽 요소이므로 배경 대비 **3:1 이상**이어야 합니다(WCAG 1.4.11). 아래 값은 흰 배경(`#ffffff`) 기준으로 계산한 결과입니다.

- **Primary**: `#3b82f6` (파란색 계열, 주요 강조) — 3.68:1, 아이콘으로 사용 가능. **텍스트 색으로는 미달**
- **Secondary**: `#059669` (초록색 계열, 성공/긍정) — 3.77:1. `#10b981`은 2.54:1로 기준 미달이라 쓰지 않습니다
- **Neutral**: `#64748b` (회색 계열, 비활성/보조) — 4.76:1, 텍스트로도 사용 가능
- **Background**: 투명(transparent)을 기본으로 하며, 필요한 경우 `#ffffff`를 사용합니다.

## 3. 선 스타일 (Stroke)
- **아이콘 두께**: `stroke-width="2"`를 기본값으로 사용합니다.
- **모서리 처리**: `stroke-linecap="round"`, `stroke-linejoin="round"`를 사용하여 부드러운 인상을 줍니다.
- **채우기**: 아이콘의 경우 선형(Outline) 스타일을 우선하며, `fill="none"`으로 설정하고 `stroke="currentColor"` 또는 브랜드 색상을 적용합니다.

## 4. 접근성 (Accessibility)
- 모든 SVG 요소에는 `role="img"`를 추가합니다.
- 색상을 바꿀 때는 [04-4의 contrast.py](../../04-4-a11y-review/scripts/contrast.py)로 3:1 충족을 확인합니다.
- `<svg>` 태그 내부에 `<title>아이콘 이름</title>`을 포함하여 스크린 리더에서 읽을 수 있게 합니다.
