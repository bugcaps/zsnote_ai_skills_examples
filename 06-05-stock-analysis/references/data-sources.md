# 조회 판정과 조회 시각

## 상태 세 가지

| 상태 | 뜻 | 이 상태를 쓰는 때 |
| :--- | :--- | :--- |
| `조회됨` | 도구로 값을 직접 읽었다 | 시세·환율 조회 도구 호출이 성공했다 |
| `사용자 제공` | 사용자가 준 값을 그대로 쓴다 | 보유 수량, 매입단가, 분류처럼 사용자만 아는 값 |
| `확인 못 함` | 값을 얻지 못했다 | 도구가 없거나, 호출이 실패했거나, 사용자가 주지 않았다 |

세 상태 말고 다른 말(`추정`, `대략`, `참고치`)을 만들지 않습니다. 셋 사이에서 망설여지면 `확인 못 함`입니다.

**쏠림 기준은 표 1에 행으로 올리지 않습니다.** 조회해서 얻는 값이 아니라 사용자가 정하는 조건이므로, 기준을 못 받았다는 사실은 표 3의 `사용자 기준 대비` 칸에 `기준 없음`으로만 나타냅니다. 같은 사실이 `확인 못 함`과 `기준 없음` 두 이름으로 나오지 않게 하려는 것입니다.

## 판정 순서

1. **능력으로 판정합니다.** "시세를 조회할 수 있는 도구가 지금 호출 가능한가"만 봅니다. 특정 증권사·서비스·API 이름을 찾지 않고, 없는 도구 이름을 지어내지 않습니다.
2. 호출 가능하면 호출하고, 응답에 적힌 기준 시각을 그대로 `조회 시각`에 옮깁니다.
3. 호출할 수 없으면 아래 대체 경로를 사용자에게 안내하고 시도합니다.
4. 대체 경로까지 막히면 `확인 못 함`으로 적고 **점검은 계속합니다.** 시세를 못 읽었다고 작업 전체를 포기하지 않습니다.

## 항목별 대체 경로

| 항목 | 순서 | 다 막혔을 때 |
| :--- | :--- | :--- |
| 보유 목록 | (1) 사용자가 붙여 넣은 목록 → (2) 사용자가 지정한 파일 | 중단. 목록 없이 시작하지 않습니다 |
| 시세 | (1) 시세 조회 도구 → (2) 사용자가 붙여 넣은 시세와 그 조회 시각 | `확인 못 함`. 매입금액 기준 점검으로 전환합니다 |
| 환율 | (1) 환율 조회 도구 → (2) 사용자가 알려 준 환율과 기준 시각 | `확인 못 함`. 통화를 섞어 합산하지 않습니다 |
| 종목 분류 | (1) 사용자가 준 분류 | `분류 미상`. 기억으로 업종을 정하지 않습니다 |
| 쏠림 기준 | (1) 사용자가 말한 기준 | 표 3의 `사용자 기준 대비`를 `기준 없음`으로. 스킬이 기준을 정하지 않습니다 |

## 기억으로 채우지 않습니다

이 스킬에서 가장 위험한 순간은 조회 도구가 없을 때입니다. 학습 시점에 알던 주가·환율·시가총액이 머릿속에 있기 때문에, 빈칸을 그럴듯한 숫자로 메우기 쉽습니다. 그 숫자는 몇 달, 몇 년 전 값일 수 있고 독자는 그것이 조회된 값인지 기억에서 나온 값인지 구분할 수 없습니다.

- 조회하지 못한 값은 **빈칸(`-`)과 `확인 못 함`** 으로 남깁니다.
- 사용자가 "대충이라도", "예전 기준으로라도" 알려 달라고 해도 채우지 않습니다. 대신 사용자가 값을 직접 알려 주면 `사용자 제공`으로 받습니다.
- 값의 자릿수나 범위("대략 5만 원대")도 적지 않습니다. 범위도 기억에서 나온 수치입니다.
- 조회한 값을 반올림하거나 보기 좋게 다듬지 않습니다. 도구가 준 숫자를 그대로 옮깁니다.

## 조회 시각

- 조회 시각은 **도구 응답에 적힌 시각**을 그대로 옮깁니다.
- **`시각 불명`과 `-`는 다릅니다.** 값은 받았는데 언제 값인지 모르면 `조회 시각` 칸에 `시각 불명`을 적고 그 행의 `상태`를 `확인 못 함`으로 내립니다. 값 자체를 못 얻어 `확인 못 함`이 된 행은 `조회 시각`이 `-`입니다.
- 사용자가 붙여 넣은 시세는 언제 본 값인지 함께 묻습니다. 대답을 못 들으면 역시 `시각 불명`이며, 그 종목의 현재가는 표 2에서 비웁니다.
- 같은 산출물 안에 조회 시각이 크게 차이 나는 값이 섞였으면(예: 30분 이상) 그 사실을 표 아래에 한 줄로 적습니다. 시각이 다른 값끼리 계산한 비중은 그만큼 어긋납니다.
- 장이 열려 있는 동안 읽은 값은 몇 초 뒤면 달라집니다. 산출물에 "현재"라는 말 대신 조회 시각을 적습니다.

## 시세가 전부 막혔을 때: 매입금액 기준 점검

사용자가 붙여 넣은 목록에는 수량과 매입단가가 있으므로, 시세가 없어도 **매입금액 기준 쏠림 점검**은 할 수 있습니다.

**모든 종목의 시세를 못 읽었으면 이 절이 우선합니다.** 종목을 `시세 확인 못 함` 한 행으로 모으는 처리(output-tables.md 표 3)는 **일부 종목만** 못 읽었을 때의 규칙이며, 전부 못 읽은 경우에 그대로 적용하면 쏠림 점검 자체가 사라집니다.

- 표 3의 금액 열 이름을 `평가금액` 대신 `매입금액`으로 바꿔 씁니다. 두 이름은 고정 목록에 함께 들어 있으며, **표 3 안에서** 둘을 섞어 쓰지 않습니다(표 2의 `평가금액` 열은 이름 그대로 남고 칸만 비웁니다).
- 표 2의 `현재가`·`평가금액`·`누적손익률`은 전부 비웁니다.
- 표 3 아래에 "시세를 조회하지 못해 매입금액 기준으로 계산했으며, 현재 비중과 다를 수 있습니다"를 적습니다.
