# 여행 일정 및 예산 계획

하루에 담을 수 있는 양을 **숫자로 먼저 정하고**, 넘친 항목을 조용히 버리는 대신 **다음 날로 옮긴 뒤 옮겼다는 사실을 적습니다**. 욕심대로 밀어 넣은 일정표를 만들지 않는 것이 이 스킬이 하는 일입니다.

## 작업 순서

1. **여행 조건과 후보를 받습니다.** 며칠짜리인지(N일)와 가고 싶은 곳 후보 목록이 둘 다 있어야 시작합니다. 하나라도 없으면 파일을 만들지 않고 사용자에게 묻습니다. 하루 용량은 **이동 시간을 포함한 활동 8시간, 주요 방문지 3곳**입니다. 주요 방문지는 체류 1시간 이상인 곳이며, 식사·휴식·이동은 방문지 수에 세지 않지만 활동 시간에는 더합니다. 사용자가 다른 숫자를 지정하면 그 숫자를 쓰되 두 산출물 머리말에 같은 숫자로 적습니다.
2. **후보를 계량합니다.** `assets/candidate-ledger.md`를 복사해 `여행계량표-<목적지>.md`로 저장하고, 후보에 1번부터 번호를 매겨 전체 M건을 셉니다. 체류 시간은 사용자가 말한 값을 쓰고, 없으면 `1시간 30분`으로 적고 출처를 `추정`으로 표시합니다. 이동 시간은 **같은 구역 30분, 구역이 다르면 60분**이고, **각 날의 첫 이동은 숙소에서 출발한 것으로 계산하며 숙소가 어느 구역인지 사용자에게 확인합니다.** 추정하는 값은 이 둘뿐이고 나머지는 추정하지 않습니다.
3. **1일차부터 채우고 넘치면 이월합니다.** 후보 순서대로 넣다가 그 항목을 넣었을 때 활동 8시간을 넘기거나 주요 방문지가 4곳째가 되면, **그 항목을 빼지 말고 다음 날 후보 맨 앞으로 옮깁니다.** **초과가 나면 그 날은 거기서 닫습니다. 뒤 후보를 당겨 채우지 않습니다.** 남은 시간을 메우려고 순서를 건너뛰면 사용자가 자기 후보 목록과 일정표를 나란히 놓고 읽을 수 없습니다. 일자마다 표 아래의 소계·이월 빈칸을 채우고, 소계가 상한 이내인 것을 확인한 뒤 다음 날로 넘어갑니다.
4. **계량표만 보고 일정표를 씁니다.** `assets/itinerary.md`를 복사해 `여행일정-<목적지>.md`로 저장합니다. **이 단계에서 원래 후보 목록을 다시 읽지 않습니다.** 계량표에 없는 곳이 일정표에 나오면 규약 위반이므로 3단계로 돌아갑니다.
5. **이월 내역·남은 후보·예산으로 닫습니다.** 이월 표와 `남은 후보` 목록을 채우고, 예산은 항목별 금액과 합계를 함께 적습니다. 합계가 항목 합과 다르거나 빈칸(`____`)이 남아 있으면 일정표를 내보내지 않습니다.

두 산출물은 사용자가 지정한 폴더에 저장하고, 지정이 없으면 별도의 작업 폴더를 만들어 씁니다. **이 스킬 폴더 안에는 새 파일을 만들지 않고 `data/`의 샘플도 고치지 않습니다**(동봉된 연습용 샘플입니다).

## 핵심 규약

- **넘친 항목은 옮깁니다. 깎거나 버리지 않습니다.** 상한을 맞추려고 체류 시간을 줄이거나 항목을 조용히 빼지 않습니다. 상한을 넘으면 초과분을 덜어 내는 규칙과 정반대로, 여기서는 초과분을 다음 날로 넘겨 살려 둡니다. 여행 후보는 덜어 내도 되는 군더더기가 아니라 사용자가 가고 싶다고 적은 목록이기 때문입니다.
- **이월은 기록이 있어야 이월입니다.** `3일차 → 4일차: 2건`처럼 옮긴 방향·건수·항목·이유를 적습니다. 옮기기만 하고 적지 않으면 사용자는 자기 목록이 왜 달라졌는지 알 수 없습니다.
- **이월한 항목은 다음 날 맨 앞에 놓습니다.** 뒤로 돌리면 같은 항목이 날마다 밀려 마지막 날에 몰립니다.
- **마지막 날에서 넘친 것은 `남은 후보`로 뺍니다.** 갈 곳이 없다고 지우지 않습니다. 일정을 늘릴지 다른 항목과 바꿀지는 사람이 정합니다.
- **모르는 값은 지어내지 않습니다.** 입장료·교통비·환율·영업시간을 기억으로 채우지 않고 `[TODO: 확인]`으로 둡니다. 예산 합계에서 `[TODO: 확인]`을 0원으로 계산하지 말고, 합계 옆에 `확인 필요 N건`을 적습니다.
- **예약도 결제도 하지 않습니다.** 항공권·숙소·입장권을 잡거나 취소하지 않고, 특정 숙소·식당 상호를 추천하지 않습니다. 구역과 활동 종류까지만 적습니다.
- **용량 숫자는 "이만큼은 된다"는 보증이 아닙니다.** 대기 줄·날씨·휴무로 실제 시간은 더 걸립니다. 상한에 딱 맞춰 채운 날이 있으면 그 사실을 일정표에 한 줄로 적어 사람이 다시 보게 합니다.

## 체크리스트

일정표를 내보내기 전에 확인하고, 하나라도 어긋나면 고친 뒤 보고합니다.

- [ ] 여행 일수와 후보 목록을 둘 다 받은 뒤에 파일을 만들었다
- [ ] 계량표가 일정표와 별도 파일로 저장돼 있고, 스킬 폴더 밖에 있다
- [ ] 두 산출물 머리말의 하루 용량 숫자가 서로 같다
- [ ] 모든 날의 활동 시간이 8시간 이하이고 주요 방문지가 3곳 이하다
- [ ] 후보 번호 1번부터 M번까지 배정·남은 후보 중 한 곳에 들어가 있고, 합계가 M과 같다
- [ ] 이월 표에 방향·건수·항목·이유가 적혀 있다(이월이 없으면 `이월 0건`)
- [ ] 마지막 날에서 넘친 항목이 `남은 후보`에 살아 있다
- [ ] 일정표의 모든 항목을 계량표에서 찾을 수 있다
- [ ] 모르는 금액이 `[TODO: 확인]`으로 남아 있고 합계에 0원으로 섞이지 않았다
- [ ] 예산 항목 합과 합계가 같고, 확인 필요 건수가 적혀 있다
- [ ] 빈칸(`____`)이 남아 있지 않다
