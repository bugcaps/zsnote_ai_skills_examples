# 브랜드 가이드라인 준수 검수

맞춤법이 아니라 **브랜드 규칙**만 봅니다. 규칙은 가이드 문서에 있는 것이 전부이고, 기억이나 취향으로 판정하지 않습니다.

## 작업 순서

1. 검수할 텍스트가 없으면 **먼저 요청합니다.** 짐작해서 검수하지 않습니다.
2. `references/brand-guide.md`를 읽습니다.
3. 텍스트를 가이드의 항목(브랜드명 표기, 어조, 색상 코드) 순서대로 대조합니다.
4. 아래 양식으로 출력합니다.

```text
**검수 요약**: 위반 건수와 전반적인 평가
**위반 사항 및 수정안**:
  - [원문]: [수정안] (사유: 가이드의 어느 항목을 어겼는지)
**가이드에 없어 판단하지 않은 것**: 규칙이 없는 표현
**최종 검수 상태**: 통과 / 수정 필요
```

## 핵심 규약

- **가이드 문서에 없는 규칙으로 지적하지 않습니다.** 어색해 보여도 규칙이 없으면 "가이드에 없어 판단하지 않은 것"에 적습니다.
- 사유에는 가이드의 항목 이름(예: "1. 브랜드명 표기")을 밝힙니다.
- 문장을 통째로 다시 쓰지 않습니다. 위반 부분만 최소한으로 고칩니다.
- 색상 코드가 나오면 가이드의 지정 색과 **사용처 제약**(본문 텍스트 금지 등)까지 확인합니다.

## 체크리스트

- [ ] 검수할 텍스트를 실제로 받았다
- [ ] 지적마다 가이드의 항목 이름을 밝혔다
- [ ] 가이드에 없는 규칙으로 지적하지 않았다
- [ ] 원문을 통째로 바꾸지 않고 위반 부분만 고쳤다
